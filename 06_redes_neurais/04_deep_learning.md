# Introdução ao deep learning

Deep learning é o uso de redes neurais com muitas camadas, capazes de aprender representações hierárquicas diretamente dos dados brutos. É a tecnologia por trás de visão computacional, processamento de linguagem e análise de imagens médicas.

Faremos um panorama das arquiteturas principais (CNNs para imagens, RNNs/Transformers para sequências), do papel dos frameworks (PyTorch/Keras) e de quando o deep learning realmente supera métodos clássicos — e quando não.
