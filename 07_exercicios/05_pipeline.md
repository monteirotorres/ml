# Exercícios — Pipeline completo

Um projeto integrador de ponta a ponta: carregar dados reais, tratar valores faltantes, pré-processar, treinar e comparar vários modelos, validar corretamente e reportar o resultado final de forma reprodutível.

Este exercício amarra todo o curso, usando `Pipeline` e `ColumnTransformer` do scikit-learn para garantir que nenhuma etapa vaze informação do conjunto de teste.
